# Demo Script

1. Show the active release and service health.
2. Open a synthetic support case in the Copilot console.
3. Ask a grounded question and show its evidence citations.
4. Show a governed KPI query and its audit outcome.
5. Demonstrate a low-risk action, then a HITL-gated financial action.
6. Open the baseline, E2E, and evaluation evidence.

Run the E2E verifier before presenting this as a completed end-to-end demo.
